Emissions are now held constant for the whole output step they apply to, instead of being linearly interpolated toward the next hour's value, and the backward run's emissions sensitivity output now sums (rather than averages) each output step's contribution and labels it with the emissions record it is actually sensitive to. These fix a mass-injection timing error in the forward run and a sensitivity accumulation/labelling error in the backward run that were found by comparing both against analytic expectations. This changes computed emissions sensitivities.
