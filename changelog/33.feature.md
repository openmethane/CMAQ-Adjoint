`ADJOINT_BWD` can now write the sensitivity of the cost function to the lateral boundary condition. Set `ADJ_LGRID_BC` to an output path to get a boundary file with the same structure, variables and time axis as the `BNDY_GASC_1` input, in `CF/ppmV`. Nothing is written if it is unset. See `docs/adj-lgrid-bc.md`.
