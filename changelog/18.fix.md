Corrected the `ADJ_LGRID_EM` emissions sensitivity file header, which described a different layer count and species list than the array actually written to it. The header is now built from the same rule the backward vertical diffusion uses to fill that array, and the backward run stops with an error if the two ever disagree. The `units` attribute is now reported as `CF/(mol/s)`, matching the emissions file units the sensitivity is taken with respect to.
